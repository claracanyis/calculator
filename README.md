# Calculator Project
This calculator has been created as the final Foundations course project for The Odin Project. It follows some base-line given in [the course](https://www.theodinproject.com/lessons/foundations-calculator) but all the code and the ideas are original. See the final result here: https://claracanyis.github.io/calculator/

# Learnings
## HTML
* Divs and buttons
* CSS and Javascript external reference

## CSS
* Different type of selectors
* Flexbox
* :hover and :active pseudoclasses
* shadows
* hsl color codes

## Javascript
* functions
* string methods
* eventListeners and the use of *event* object
* DOM reading and modification
* switch conditional
* function calling from other funtions
* local and global variables
